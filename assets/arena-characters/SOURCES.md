# Arena character assets

The `clean` folder contains locally hosted transparent character PNGs from the
[RoyaleAPI Clash Royale asset repository](https://github.com/RoyaleAPI/cr-api-assets).
The supplied JPG references are preserved in the parent folder.

These assets are used for this non-commercial clan fan tracker. This material
is unofficial and is not endorsed by Supercell. See the
[Supercell Fan Content Policy](https://supercell.com/en/fan-content-policy/).
